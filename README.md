## 🌐 Présentation du projet

**Ph-DevAI** est une application web moderne conçue avec **Flask** – inspirée de **Canva 🎨**, pour offrir aux utilisateurs un espace professionnel où **créer, gérer et développer leurs projets**.  

Ce projet est un **sous-domaine du Domaine PH**, une initiative fondée par **Prince Hilquia** :  
> un écosystème qui unit **science, foi et technologie** pour inspirer la jeunesse et transformer des idées en réalités.  

**🎯 Mission :** Connecter les talents, amplifier les rêves et bâtir un monde meilleur grâce à la technologie 🚀.

---

## 🧭 Comment utiliser l’application

1. 🌐 **Accédez à la page d’accueil (`index.html`)**  
   → Cliquez sur **Créer un compte** pour rejoindre la communauté Ph-DevAI.  

2. 🧑‍💻 **Connectez-vous à votre tableau de bord**  
   → Depuis votre espace personnel, créez un projet et suivez sa progression.  

3. 💬 **Collaborez avec notre équipe**  
   → L’équipe Ph-DevAI vous contactera directement via l’application pour poursuivre le développement de votre idée.
